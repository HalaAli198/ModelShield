Ethical Considerations

1. Controlled Execution Environment

   All analysis was performed in isolated virtual machines containing
   no real user data, credentials, or sensitive information. 

2. Responsible Disclosure

   All confirmed real-world malware was reported to the relevant
   platform security teams (Hugging Face Security, AWS Trust & Safety)
   prior to publication. Detailed disclosure timelines are documented
   in each security advisory under Security_Advisories(Real_Malware_Cases)/
   in the repository root.

3. Malicious Model Handling

   The public release includes five representative repositories from
   the 41 malicious models detected on Hugging Face
   (Test_Suites/41_Malicious_Models/). All five are proof-of-concept
   samples. The remaining 36 repositories are not redistributed, as
   the set includes live payloads; neither of the two real-world
   malware samples (LQCTestingSpace/lqc_model and
   cgruzicka/test-lora-weights) is included. Traces and verdicts for
   all 41 models are provided in
   All_Results/Detection_Results_41_Malicious_Models/.

   The crafted evasion variants and TensorFlow API abuse attacks are
   included, as they reproduce previously published techniques
   (Liu et al., 2025; Zhu et al., 2025). The gadget substitution and
   loading-path variants access only a dummy SSH key created by
   install.sh, and the TensorFlow attacks target a private address
   (192.168.29.129) that stands in for the attacker's server. The
   PickleBall dataset (Kellas et al., 2025) is not redistributed; it
   is available from its original record at
   https://doi.org/10.5281/zenodo.16974644.

   All included samples execute their payloads when loaded or run and
   must be executed only inside an isolated virtual machine.
